# walkietalkie-chat-app


> Real-time chat application with walkie-talkie vibes


## 🚀 Features

- 🔐 JWT Authentication
- 💬 Real-time messaging with Socket.io
- 🟢 Online/Offline status
- 📸 Image uploads (Cloudinary)
- 📧 Welcome emails
- 🛡️ Rate limiting (Arcjet)
- 🎨 Beautiful UI with Tailwind CSS


## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Socket.io
- JWT
- Cloudinary
- Arcjet

### Frontend
- React
- Vite
- Tailwind CSS
- DaisyUI
- Zustand
- Socket.io-client
